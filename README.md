# 心臓人狼

デッキの40枚のうち1枚が、自分の「心臓」。カードを使うほど正体は透けていく。相手の心臓を3回射抜いた方の勝ち、というカードゲームです。

**遊ぶ:** https://pteratakahashi.github.io/shinzou-jinrou/

## 友達と対戦する

1. メニューの「友達と対戦（オンライン）」を開きます。
2. 一人が「部屋を作る」を押し、出てきたリンク（または5文字の部屋コード）を友達に送ります。
3. 友達はリンクを開いて「参加する」を押します。
4. つながったら、おたがいにデッキを用意します（7パック開けて組む／おまかせデッキ／前と同じデッキ）。両方そろうと対戦が始まります。

- 通信はブラウザどうしを直接つなぎます（[PeerJS](https://peerjs.com/)）。サーバーにゲームの内容は残りません。
- 部屋を作った人の画面でゲームが進みます。部屋を作った人がページを閉じると対戦は終わります。
- 学校・会社のネットワークや一部の回線では、つながらないことがあります。

## CPU と対戦する

メニューの「CPUと対戦」から、一人でも遊べます。

## ファイル

- `index.html` … ゲーム本体（1ファイル）
- `art/` … カードのドット絵
