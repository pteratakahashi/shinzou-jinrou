# 心臓人狼

デッキの40枚のうち1枚が、自分の「心臓」。カードを使うほど正体は透けていく。相手の心臓を3回射抜いた方の勝ち、というカードゲームです。

**遊ぶ:** https://shinzoujinro.com/

## 友達と対戦する

1. メニューの「友達と対戦（オンライン）」を開きます。
2. 一人が「部屋を作る」を押し、出てきたリンク（または5文字の部屋コード）を友達に送ります。
3. 友達はリンクを開いて「参加する」を押します。
4. つながったら、おたがいにデッキを選びます（自分のデッキ／スタンダードデッキ／前と同じデッキ）。両方そろうと対戦が始まります。

- 通信はブラウザどうしを直接つなぎます（[PeerJS](https://peerjs.com/)）。サーバーにゲームの内容は残りません。
- 最初のつなぎ役（シグナリング）と、直接つなげない回線用の中継（TURN）は自前の VPS で動かしています（`peer.shinzoujinro.com`）。
- 部屋を作った人の画面でゲームが進みます。部屋を作った人がページを閉じると対戦は終わります。
- 学校・会社のネットワークや一部の回線では、つながらないことがあります。

## 観戦する

メニューの「試合を観戦する」を押すと、いま対戦中の誰かの試合をランダムに見られます（1試合に8人まで）。観戦中は、どちらの手札と心臓も見えません（使われたカードと、相手に知られたカードだけが見えます）。対戦中の部屋の一覧は Supabase に置いています（`supabase/setup.sql` の `live`）。

## レート戦

おたがいがGoogleでログインしていると、友達対戦がレート戦になり、メニューに戦績・レート・ランク・順位が出ます。サーバーの設定方法は [supabase/README.md](supabase/README.md)。

## カードを集める

- 最初は全員が同じスタンダードデッキ（Sのカード13種×3枚＋〈名探偵〉）を持っています。
- ランクマッチ（待機列でつながった対戦）が確定すると、勝った人に2種、負けた人に1種、全カードからランダムにカードが配られます（かぶることもあります）。1種もらうと、そのカードをデッキに3枚まで入れられます（シングルは1枚）。
- はじめて Google でログインすると5パック、はじめてのランクマッチ（決着した試合）で5パックがもらえます（1パック5枚。1〜3枚目 ブロンズ70%/シルバー30%、4枚目 シルバー70%/ゴールド30%、5枚目 ゴールド80%/レジェンド20%。同じレアリティの中から完全にランダム、1パックの中では同じカードは出ない）。パックの数と開封はサーバー（`packs` テーブル、`pack_state` / `open_pack`）
- はじめて Google でログインすると5パック、はじめてのランクマッチ（決着した試合）で5パックがもらえます（1パック5枚。1〜3枚目 ブロンズ70%/シルバー30%、4枚目 シルバー70%/ゴールド30%、5枚目 ゴールド80%/レジェンド20%。同じレアリティの中から完全にランダム、1パックの中では同じカードは出ない）。パックの数と開封はサーバー（`packs` テーブル、`pack_state` / `open_pack`）。ゲームのカードやレアリティ（RANK・BASIC_ROLES）を変えたら、setup.sql のパック用の一覧（tier・starter）も作り直す
- 部屋を作る友達対戦では、カードはもらえません。ランクマッチの後は再戦ボタンはなく、次の相手を探します。
- 持っているカードはサーバー（`collection` テーブル）にあり、ホームの「デッキ編成」で使えます。報酬を配るのはサーバー側の関数だけです。

## CPU と対戦する

メニューの「CPUと対戦」から、一人でも遊べます。

## ファイル

- `index.html` … ゲーム本体（1ファイル）
  - カードを足したり、勝率順（`RANK`）・レジェンド（`LEGEND_N`）を変えたら `python3 supabase/gen_cards_sql.py` で setup.sql のカード表を作り直し、Supabase で流し直す
  - 勝率順は CPU どうしのシミュレーション（ランダムデッキ）で取る。ページの中で `S.sim` を立てると待ち時間なしで回せる（2026-11-09 は12,000試合）
  - 遊ぶ人に見える変更をしたら、`index.html` の `UPDATES`（トップ画面のアップデート情報）の先頭に1行足す（id は1つ増やす）
- `art/` … カードのドット絵（背景は透過。系統の色はゲーム側で敷く）
- `supabase/` … レート用のデータベース設定と手順

## 開発メモ
- アドレスは `shinzoujinro.com`（`CNAME`）。旧アドレス pteratakahashi.github.io/shinzou-jinrou は GitHub が自動で移す。端末内の保存は、別リポジトリ `sj-move`（pteratakahashi.github.io/sj-move/、旧アドレスと同じ場所）を一度経由して受け取る（index.html 先頭の引っ越しスクリプト）
- `index.html` を更新して公開するときは、`const APP_VER='…'` を今の日時（UTC、例：20261104021500）に書きかえること。開いたままの人に「更新」ボタンが出るのと、友達対戦で版がちがう人どうしをつながないようにするのに使っている
- 書きかえは `const APP_VER='` の部分だけにする（更新チェックの正規表現 `APP_VER='(\d+)'` は書きかえない）
